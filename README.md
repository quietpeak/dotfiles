# macOS Dotfiles

Starter `.zshrc` and Homebrew `Brewfile` template for a clean macOS terminal setup.

## Usage

    brew bundle --file=Brewfile.example
    cp .zshrc.example ~/.zshrc

## Included Files
- `.zshrc.example`: Minimal Zsh aliases and editor defaults.
- `Brewfile.example`: Core CLI tools installed via Homebrew.
